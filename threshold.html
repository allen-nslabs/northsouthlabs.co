Project Threshold

A two-player co-op horror shooter. This is an early playtest build: four levels, unsigned, and rough in places.

Mac

The app isn't notarized, so macOS will block it on first open. After the download finishes, paste this into Terminal:

cd ~/Downloads && unzip -oq ProjectThreshold-0.3.0-macos.zip -d Threshold-0.3.0 && xattr -dr com.apple.quarantine Threshold-0.3.0 && open "Threshold-0.3.0/Project Threshold.app"

Before you play

  • Both players need this same build to play together.
  • Two monster hits put you down. Setting Personal toughness to Very tough in Settings gives you four.
  • Press F8 in game to save a problem report.
